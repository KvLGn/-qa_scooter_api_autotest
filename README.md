# API автотест для Яндекс Самокат

Ковалев Александр, 47-я когорта — финальный проект

## Описание

Автоматизированный тест для проверки API создания и получения заказа в сервисе Яндекс Самокат.

## Сценарий теста

1. Отправить POST-запрос на создание заказа.
2. Сохранить номер трека заказа из ответа.
3. Отправить GET-запрос на получение заказа по треку.
4. Проверить, что код ответа равен 200.

## Структура проекта

- `configuration.py` — URL сервера и пути API
- `data.py` — заголовки и тело запроса
- `sender_stand_request.py` — функции отправки запросов
- `test_order.py` — автотест

## Запуск

```bash
pip install requests pytest
pytest test_order.py
```
